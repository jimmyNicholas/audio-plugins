# Band Spread shift audition: how to test it

**PROTOTYPE, throwaway.** One Max for Live audio effect, **Band Spread Shift Audition.amxd**. It cuts one narrow Band out of the input and plays three Copies of it, through either a pitch shift engine or a frequency shift engine. Your notes settle [#24 Does Band Spread shift by pitch or by frequency?](https://github.com/jimmyNicholas/audio-plugins/issues/24). Post them on that ticket.

It is generated by `build-patch.mjs` (`npm run build` here). Never edit the `.maxpat` by hand.

## Getting started

1. Fetch and switch to the branch `claude/band-spread-shift-audition`.
2. Optional: from the repo root, run `npm test`. The last lines should show `# fail 0`.
3. In Live 11's browser, under **Places**, click **Add Folder…** and choose `devices/band-spread/prototype` inside your `audio-plugins` checkout.
4. Check **Options > Delay Compensation** is ticked. Use 44.1 or 48 kHz.
5. Start with the track volume down. **Gain** starts at +12 dB, because a narrow band is quiet, and there is a hard clip at 0 dBFS as a safety. If it crackles, the clip is working: lower **Gain**.

### Test material

Three tracks, as the ticket asks: a **drum loop**, a **pad** (a held chord, eg a Wavetable or Analog preset), and a **voice** (any vocal clip, sung or spoken). Put the device on one track at a time.

## The panel

| Area | Control | What it does |
|---|---|---|
| BAND | **Centre** | The Band's centre, 40 Hz to 12 kHz. Starts at 800 Hz |
| | **Width** | The Band's width in octaves, 0.1 to 3. Starts at 0.5 |
| | **Stages** | 1, 2 or 3 band pass stages in series. More is steeper and a little narrower. Starts at 2 |
| | **Band On / Off** | Adds the unshifted Band, so you can hear what the Copies are made from |
| ENGINE | **Engine** | **Pitch**: each Copy is pitch shifted by its **Semis** dial. **Freq match**: each Copy is frequency shifted by the Hz that puts the Band's centre where Pitch would (shown below the tab). **Freq Hz**: each Copy is frequency shifted by its own **Hz** dial |
| | **Gain** | Output level, -12 to +36 dB |
| | Readouts | **PS latency** (the pitch engine's measured latency, expect 4096), **Defined Latency: 8192 smp**, and the Hz each Copy is shifted by in the frequency engines |
| COPY 1 to 3 | **Semis** | Pitch shift, -24 to +24 semitones. Used by **Pitch** and **Freq match**. Starts at -12, +7, +12 |
| | **Hz** | Frequency shift, -3000 to +3000 Hz. Used by **Freq Hz** only. Starts at -300, +400, +1000 |
| | **Level** | The Copy's level. At its minimum (-70 dB) the Copy is off |

When you change **Engine** between Pitch and a Freq mode, the old engine fades out at once and the new one fades in about a quarter of a second later. Judge the sound a moment after a switch. Switching between **Freq match** and **Freq Hz** glides over 20 ms instead.

Both engines are delayed to the same total (8192 samples), so switching never jumps in time and Live keeps the track in sync.

## Stage 2: Pitch against Freq match

Same Band, same target positions, two kinds of shift. This is the heart of the question.

Set **Band Off**, all three Copies at -6 dB, **Engine: Pitch**. Then switch to **Freq match** and back, a few times per source.

| #   | Source                                            | Listen for                                                                                                           | Pitch or Freq match? Why?                                                       |
| --- | ------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 2.1 | Pad                                               | Which sounds more musical, which more interesting                                                                    | Freq just slightly more interesting but both are good. I like having the choice |
| 2.2 | Drum loop                                         | Transients: does one smear or flam more? (Pitch has a 93 ms internal window)                                         | Seems fine                                                                      |
| 2.3 | Voice                                             | Does the voice stay a voice? Which is more usable?                                                                   | Out of scope                                                                    |
| 2.4 | Pad, **Width 2** or wider                         | With a wide Band, Freq match goes inharmonic (bell-like) because every partial moves by the same Hz. Do you like it? | seems fine                                                                      |
| 2.5 | Any, **Centre** low (eg 150 Hz) and a Copy at -12 | Freq match: a Copy may cross 0 Hz and fold back up. Pitch never crosses 0 Hz                                         | It crosses to negative                                                          |

## Stage 3: Freq Hz on its own

The frequency shift with its own unit: a fixed number of Hz, the same whatever the **Centre**.

| #   | Do                                              | Listen for                                                                                                | Notes                                                       |
| --- | ----------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 3.1 | **Engine: Freq Hz**, then move **Centre**       | The Copies keep a fixed distance in Hz from the Band, so their musical interval changes as the Band moves | correct                                                     |
| 3.2 | Turn one Copy's **Hz** slowly through 0         | The Copy passes through the Band and out the other side. Below 0 Hz it folds back                         | correct                                                     |
| 3.3 | Small shifts (eg +5 to +30 Hz)                  | Beating and phasing against the Band (turn **Band On**). Useful, or not?                                  | I like this effect. Beating without band on, better when on |
| 3.4 | Large shifts (eg +2000 Hz) with **Centre** high | Near the top, a Copy past half the sample rate may alias back down                                        | it's fine                                                   |

## Troubleshooting

- **No sound:** check **Gain** and the Copy **Levels**, and that the track is not muted. Turn **Band On**: if the Band is silent too, the filter did not load (look in the Console for `filtercoeff~` or `biquad~`).
- **"No such object" in the Console:** send me the line. `filtercoeff~`, `biquad~`, `freqshift~` and `clip~` are new to this repo and have not been loaded in Live before.
- **PS latency stays "not measured yet":** switch **Engine** to a Freq mode and back to **Pitch**, which measures again.
