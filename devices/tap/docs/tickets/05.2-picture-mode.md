# 05.2: Picture mode

**Goal:** a pixel art picture in the drift window that scrambles as the piano drifts and comes back together on Reset.

## Decided with the user (2026-10-12)
- **Built-in pixel art**, drawn into the code: a landscape. No image files. Loading your own image could be a later ticket.
- **A Keys / Picture toggle** at the top of the pop-out window. Same window, same size.

## How the picture follows the pitch table
- The picture is a 16 by 8 grid of squares, one per MIDI note. Note 0 is the top-left square and the notes run in reading order. Square *n* belongs to note *n*.
- Each slot shows the square for the pitch its key now plays: slot *k* shows square *k* + (drift of key *k* in semitones).
  - **Swap:** two keys trade pitches, so their squares trade places. The picture scrambles like a sliding puzzle.
  - **Move:** the key shows the square one or two notes along.
  - **Gravity:** pitches fall between notes, so the slot blends the colours of the two nearest squares (the "warp").
  - Pitches outside 0 to 127 show the nearest edge square.
- At concert pitch every slot shows its own square, so Reset and mode changes put the picture back together.

## Tasks
- `drift-view.js`, test-first against the fake `mgraphics`:
  - A small set of built-in 16 by 8 pictures (start with one; a few to choose from if they are cheap), stored as palette indices.
  - The slot to square mapping above, as a plain function with its own tests: whole-note drift, blends, out of range, concert pitch.
  - Drawing: square grid centred in the window, about 22 pixels a square.
  - The toggle: clicking Keys or Picture in the header switches the view. It is remembered while the window is open; it is not a Live parameter.
  - Hover in Picture mode shows the same text as in Keys mode for the key under the mouse.
- No change to `tap.js` or the note path: the view already gets all 128 offsets after each change.
- Regenerate the device only if the patch changes (it should not need to).

## Prototype
Open the drift window, switch to Picture. Swap scrambles squares in pairs, Move shifts them, Gravity smears colours. Reset puts the picture back together.

## Done when
- Tests pass, including the ES5 check.
- Picture mode adds no delay to notes (the same fast passages as ticket 01, with the window open on Picture).
