# 17: Floor at the same note name

**Status:** parked. For later; not part of tickets 11 to 15.

**Idea (the user, 2026-10-25):** limit how far a key can fall to the nearest note below with the same name. If you play A4 and Gravity pulls it down, it stops at the A below (A3) instead of going on down towards C.
