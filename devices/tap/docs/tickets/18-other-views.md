# 18: Other views

**Status:** parked. Start after ticket 15 (the square view) is built. Then pick one or two of these to grill.

**Idea (the user, 2026-10-26):** other ways to show or warp the drift, alongside the square view. Each uses the 128 offsets `tap.js` already sends, so none needs an engine change.

## The user's picks

- **Pitch-class circle:** twelve spokes (C to B), with each octave a ring further out. Drift turns a key's dot around the circle, so it shows when a key lands on another note name.
- **Rubber sheet:** a grid that bends where keys drift, as if each key pulled the sheet up or down. Gravity shows as dents pulling together.
- **Warped picture:** a picture that stretches and smears where keys drift, instead of trading squares as Picture mode did. Picture mode's code is in the history from ticket 05.2.

## Not picked

- **Crossing lines:** two rulers, concert pitch below and played pitch above, with a line from each key to where it plays.
- **Waterfall:** time scrolling down, one column per key, colour for drift.
